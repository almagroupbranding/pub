# Alma website wording tidy v3

This update tidies the customer-facing wording so the site feels ready for real pub customers, not like an internal project or consultant review.

## Main changes

- Removed behind-the-scenes language such as “current site”, “platform clutter”, “commercial role” and “waste staff time”.
- Made the homepage more direct and welcoming.
- Made food wording clearer and more customer-ready.
- Tidied the venue hire page so it is firm but not unfriendly.
- Made events wording clearer and less internal.
- Kept `site-config.js` protected with the live Worker URL.
- Kept the menu/signage PDFs and public-facing menu content.

## Why this matters

The customer should understand within five seconds:
- what The Alma is;
- why they should visit;
- what they can do next.

This version is more polished, calmer and more suitable for a live pub website.
