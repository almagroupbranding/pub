# Phase 2 — Pages CMS Setup

This repository now includes `.pages.yml`, which is the Pages CMS configuration file.

## What the owner can update

Pages CMS can edit:

- Site settings
- Opening times
- Food serving times
- Events
- News updates
- Food/menu highlights
- Gallery images and captions

## Setup

1. Go to Pages CMS.
2. Sign in with GitHub.
3. Install/authorise it for the `almagroupbranding/pub` repository.
4. Pages CMS will read `.pages.yml`.
5. Edit content.
6. Save/publish. Pages CMS commits the change back to GitHub.
7. GitHub Pages republishes the site.

## Important

Phase 2 gives them the dashboard-style editing experience.
Phase 3 should add live calendar approval and direct form submission.
